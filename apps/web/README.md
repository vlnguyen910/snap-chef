# Snap Chef Web

This is the frontend web application for Snap Chef, built with [Vite](https://vitejs.dev/) and [React](https://react.dev/).

## Getting Started

### Prerequisites

- Node.js (>= 18)
- pnpm

### Environment Variables

See `.env.example` (if available) or consult the team for required environment variables.

### Installation

```bash
pnpm install
```

### Running the App

```bash
# development
pnpm run dev

# build for production
pnpm run build

# preview production build
pnpm run preview
```

### Linting

```bash
pnpm run lint
```

### Type Checking

```bash
pnpm run check-types
```
